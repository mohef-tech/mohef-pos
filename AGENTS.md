# Workspace Rules - cp-moheftech

Before auditing, designing, writing UI/copy, or editing any code in this project, always read and follow `.agents/skills/mohef-skills/SKILL.md` and `.agents/skills/ui-ux-pro-max-skill/SKILL.md` first.

Mandatory defaults for every session:
- Follow the `Communication Rules` in `SKILL.md` (respond in Indonesian, execute 1 step at a time and wait for confirmation, no post-task summaries unless asked).
- For UI redesign or refactoring, always run Audit -> Direction -> wait for user approval before editing any file.
- Do not touch backend logic, database schema, or `/admin` unless explicitly requested.

Wajib membaca dan mematuhi prd_pos_mohef_tech_v1.md sebagai source of truth untuk seluruh batasan fitur V1 sebelum membuat file atau menulis kode. Gunakan skill yang tersedia di .agents/skills/ dan jalankan tugas secara ketat satu per satu dengan menunggu konfirmasi pengguna sebelum melanjutkan.

- Baca PROGRESS.md HANYA jika kamu kehilangan konteks proyek atau jika diminta secara eksplisit. Namun, kamu WAJIB memperbarui PROGRESS.md secara mandiri setiap kali berhasil menyelesaikan suatu langkah besar atau fitur.
